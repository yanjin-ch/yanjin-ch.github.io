cps-backup

cps-backup is a private, single-user backup tool. Its owner runs it to keep encrypted daily backups of their own small-business database in their own Google Drive. It is not offered to the public and has no other users.

cps-backup 是一個私人、單一使用者的備份工具：擁有者用它把自己小型店務資料庫的加密每日備份，存到自己的 Google 雲端硬碟。不對外提供，沒有其他使用者。

What it does with Google Drive / 如何使用 Google 雲端硬碟

  • It asks only for the drive.file permission: it can see and manage only the files it created itself. It cannot read any other file in the Drive.
    只要求 drive.file 權限：只能存取它自己建立的檔案，看不到雲端硬碟裡的其他檔案。
  • It uploads one encrypted backup file per day, downloads it back to check it is intact, and removes its own old backups on a fixed retention schedule.
    每天上傳一份加密備份、下載回來核對完整性，並依固定保留規則刪除自己較舊的備份。
  • Backups are encrypted before upload; only the owner's private key can open them.
    備份上傳前已加密，只有擁有者的私人金鑰能解開。
